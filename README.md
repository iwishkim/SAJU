# 명리와 귀곡 · 사주 해설

현재 배포본은 v5입니다. 대운수·10년 구간·현재 대운 강조를 원본의 날짜 단위 절입 차이와 세는나이 기준으로 변경했습니다. 예시 음력 1980-08-08 남성은 대운수 7, 2026년 현재 대운 庚寅(47–56세)입니다.

압축을 풀고 index.html을 더블클릭하세요. HTML/CSS/JavaScript만 사용하며 설치·서버·빌드 없이 동작합니다. 정적 웹호스팅에도 폴더 구조 그대로 업로드할 수 있습니다.

## 기능

- 양력·한국 음력·윤달, 출생 시각, 일주 변경 기준 선택
- 사주 원국, 십신, 지장간, 오행 개수, 대운·세운
- 원본의 조건 분기를 복원해 사주별로 선택하는 귀곡산명술 해설과 보충문장
- 근본성격 / 부모형제운 / 배우자운 / 자녀운 / 사업운 / 초년운 / 중년운 / 말년운 / 종합해설
- 해설만 인쇄·PDF 또는 원국·해설·대운 전체 인쇄
- 모든 해설을 TXT 파일로 저장
- 출생 입력값 브라우저 저장·삭제

## 해설의 범위

v4는 기존 설치 파일의 guikok.db 641행, EYCONV.db 절입표, 내부 실행 파일의 해설 선택 함수 9개에서 추출한 문장 선택 분기 634개를 사용합니다. v3의 본기 고정 규칙을 제거하고 절입 경과일별 지장간 선택 및 원본의 성별·구성별 보충문장 조건을 적용했습니다. 원본 프로그램은 실행하지 않았습니다.

제공된 1970-02-06 남성 사주의 근본성격 첫 문장이 원본 화면의 HA(401)과 일치합니다. 모든 사주를 원본 화면과 실제 대조한 것은 아닙니다. 종합해설은 선택된 본문의 첫 문장을 모은 웹앱 요약입니다.

원본 코드에서 참조하나 데이터에 없는 문장 6개(HA304, HB211, HB511, HD604, HE612, HF902)는 임의 대체하지 않고 해당 조건에서 누락을 안내합니다. 귀곡 절입표의 지원 범위는 1901~2050년이며 이전 절입 자료가 없는 1901년 1월 초는 제외합니다.

## 로컬 수정

| 파일 | 역할 |
| --- | --- |
| index.html | 화면 구성과 입력 항목 |
| styles.css | 화면과 인쇄 디자인 |
| app.js | 화면 표시·TXT·인쇄·입력 저장 |
| engine.js | 달력과 사주 계산 |
| daeyun.js | 원본 방식 대운수·순역·구간·현재 대운 계산 |
| guikok.js | 사주별 해설 선택과 종합 요약 |
| guikok-native.js | 원본 표를 이용한 지장간·분류값 계산과 조건 평가 |
| data/guikok.js | 브라우저가 실제 읽는 641개 해설 문구 |
| data/guikok-native-rules.js | 원본에서 정적으로 추출한 대응표와 634개 조건 분기 |
| data/guikok-calendar.js | 브라우저가 읽는 원본 절입표 |
| data/guikok-calendar.json | 원본 절입표의 읽기 편한 사본 |
| data/guikok.json | 읽기 편한 원문 사본. 이 파일만 수정하면 화면에 반영되지 않음 |
| vendor/ | 달력 자료와 계산 라이브러리, 라이선스 |

수정 후 저장하고 브라우저에서 새로고침하세요. JS 해설 문구의 따옴표·쉼표 등 문법은 유지해야 합니다. JS·JSON 자료에는 원문에 포함된 끝문자 \u0000이 있으며 화면 표시와 TXT 저장에서는 제거합니다.

입력값은 저장 버튼을 눌렀을 때만 localStorage에 저장됩니다. 외부 서버로 전송하지 않습니다. 브라우저나 호스팅 주소를 바꾸면 저장한 입력이 자동 이전되지 않습니다. file://에서는 브라우저별 저장 정책에 따라 저장 기능이 제한될 수 있으나 기본 계산·해설은 저장소 없이 작동합니다.
